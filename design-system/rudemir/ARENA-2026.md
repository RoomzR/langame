# RUDEMIR · Arena 2026

Редизайн поверх HUD-системы. Референсы: RAVE by Buster (энергия: гигантский узкий капс, рваные срезы блоков, чёрный + один кричащий цвет, моно-подписи), LANGAME (продуктовый лоск: большая тёмная карточка-герой с радиусом 24, свечение, мокап приложения, кнопки сторов). Ни один из них не копируется: у RUDEMIR свой цвет, свой шрифт, своя фишка.

## Что меняется

| Было (HUD) | Станет (Arena) |
|---|---|
| Unbounded, широкий, 80px | Sofia Sans Extra Condensed 900, капс, 120–200px, кернинг −2% |
| Radius ≤ 8, ровные плиты | Два радиуса: 0 у «афишных» блоков и 24 у продуктовых карточек |
| Сетка 32px на фоне | Косой срез 6° (clip-path) между секциями и на медиа |
| Синий + коралл поровну | Один кричащий цвет — синий #2015FF как заливка целых блоков; коралл уходит в цену и статус «занято» |
| Тихая шапка | Шапка прозрачная поверх героя, при скролле — чёрное стекло (blur 16) |
| Hero: заголовок слева, карта справа | Hero: полноэкранный синий блок с срезом, заголовок в 3 строки капсом, карта зала в изометрии (perspective 3D), живой счётчик |

## Токены

| Name | Hex | Роль |
|---|---|---|
| `--ink` | `#050505` | фон |
| `--paper` | `#F4F4F2` | контрастные секции («Как это работает», футер) — белые полосы как у афиши |
| `--blue` | `#2015FF` | заливка блоков, CTA, свободное место |
| `--blue-deep` | `#120B99` | тень/градиент внутри синих блоков |
| `--coral` | `#FF6A3D` | цена, занято, ошибка |
| `--glass` | `rgba(20,20,22,.72)` | карточки поверх медиа, шапка при скролле |
| `--line` | `rgba(255,255,255,.12)` | делители |

Текст: белый на ink/blue, `#050505` на paper, вторичный `#9A9A9A` / `#5C5C5C`.

## Тип

- Display: **Sofia Sans Extra Condensed** 800/900, капс, `letter-spacing: -0.02em`, `line-height: 0.9`. Шкала: 200 / 120 / 72 / 48 / 32.
- Body: **Manrope** 400/500/700, 16/18, `line-height 1.5`.
- Data: **JetBrains Mono** 500, 12–14, капс — только цифры табло, метки мест, время. Как у Rave моно-подписи, но без пиксель-стилизации.

## Слои и формы

- **Афиша** (radius 0, срез 6°): hero, полосы-манифесты («Топовое железо. Настоящие турниры.» — у нас: «Свободно сейчас. Бронь за минуту. Оплата в Br.»), футер.
- **Продукт** (radius 24, glass): карточки клубов, панель брони, кабинет, консоль. Внутренние элементы радиус 12, кнопки 12.
- Кнопки: primary — синяя заливка, белый капс-текст Sofia 20px, hover — сдвиг вверх 2px + тень `0 12px 40px rgba(32,21,255,.45)`. Ghost — белая обводка 1.5px.
- Срез: `clip-path: polygon(0 0, 100% 0, 100% calc(100% - 48px), 0 100%)` на десктопе, 24px на мобиле.

## Страница клуба

- Медиа-шапка на всю ширину 56vh: фото зала (если есть) или синий градиент-glow, срез снизу. Поверх — название клуба капсом 120px, адрес моно.
- Под срезом две колонки: слева карта зала (та же изометрия, но плоская при выборе), цены, железо; справа sticky glass-панель брони с радиусом 24 и синей кнопкой 56px «Бронь».
- Мобайл: панель брони — нижний лист, кнопка «Бронь · 12.00 Br» прижата к низу над bottom-bar.

## Фишка

Изометрическая карта зала. На hero и на странице клуба зал лежит под углом (`transform: rotateX(55deg) rotateZ(-45deg)`), места — плитки с высотой (box-shadow «толщина» 6px). Свободные — синие, светятся; занятые — тёмные с коралловой кромкой. Hover — плитка поднимается на 8px. Клик — плитка мигает дважды и панель брони подставляет место. На мобиле — та же карта, но без наклона, горизонтальный snap. Это единственная 3D-вещь на сайте.

## Движение

- Загрузка hero: синий блок выезжает срезом снизу 480ms, заголовок построчно 3×80ms, карта поднимается из плоскости 600ms. Один раз, только на лендинге.
- Бегущая строка 40s linear, пауза на hover.
- Шапка: прозрачная → стекло за 200ms после 80px скролла.
- `prefers-reduced-motion`: всё статично, изометрия остаётся.

## Голос

Капс — только в display. Кнопки как раньше, 1–3 слова. Манифесты — короткие приказы с точкой: «ВЫБЕРИ КЛУБ.», «ВОЗЬМИ МЕСТО.». Без восклицаний, без «легендарных».

## Не делаем

Рваные края «в клочья», глитч на кнопках, фото людей со стоков, красный, пиксельные шрифты, шестиугольники, 3D-бейджи. Это чужое.
